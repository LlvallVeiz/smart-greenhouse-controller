# Examples

Three ready-made run configurations (JSON, loadable by
`greenhouse simulate` / `greenhouse compare`) plus their real outputs
in `output/`, generated by `examples/run_examples.sh`.

| Config | Crop | Climate | What it shows |
|---|---|---|---|
| `config_tomato.json` | Tomato | Warm (outdoor mean 20 °C) | The headline 7-day run: 520 L water, 63.6% in band |
| `config_lettuce.json` | Lettuce | Cool (outdoor mean 16 °C) | Cool-season crop in a climate it can tolerate: 53.1% in band |
| `config_cucumber.json` | Cucumber | Warm, seed 7 | A different weather draw: 560 L, 61.3% in band |

`output/` contains, per run: `timeseries.csv`, `timeseries.json`,
`report.md`, `dashboard.html` (open in a browser; Chart.js from CDN)
and, where generated, `climate.png` / `soil.png`.

Reproduce everything with:

```bash
bash examples/run_examples.sh
```

Or run one config by hand:

```bash
PYTHONPATH=src python3 -m smart_greenhouse_controller simulate examples/config_tomato.json --out output --charts
PYTHONPATH=src python3 -m smart_greenhouse_controller compare examples/config_tomato.json --out output-compare
```
